Profil website pribadi dibuat dengan menggunakan HTML untuk mengatur struktur dan konten halaman, serta CSS untuk memeperindah tampilan website. HTML digunakan untuk membangun bagian-bagian seperti profil, hobi, pendidikan, dan kontak. Sedangkan CSS digunakan untuk mengatur warna, jenis huruf, penataan tampilan, ukuran ,serta berbagai elemen visual lainnya. Pembuatan website dimulai dengan menyusun struktur HTML, selanjutnya mengatur tampilan menggunakan CSS, lalu menambahkan navigasi dan menyesuaikan tampilan agar tetap nyaman digunakan baik dilayar komputer maupun diponsel.

Kenapa Harus Membuat Website Profil Pribadi?

Website profil pribadi dibuat agar dapat menampilkan informasi tentang diri seseorang dengan cara yang lebih menarik dan teratur. Melalui website ini, informasi seperti profil, hobi, pendidikan, dan kontak dapat ditampilkan secara lebih rapi. Selain itu, website profil pribadi juga bisa jadi cara untuk memeperkenalkan diri kepada orang lain melalui media digital. Pembuatan website ini juga memberikan kesempatan untuk mencoba mengubah ide menjadi tampilan webite. Mulai dari menetukan bagaimana susunan informasinya, memilih warna yang sesuai, hingga mengatur tampilan desain agar sesuai dengna apa yang diinginkan. Dari proses itu, website profil pribadi bukan hanya tempat menampilkan informasi, tetapi juga runag untuk mencoba hal baru, mengembangkan kreativitas, dan memahami labih lanjut dalam cara membuat sebuah website.

Tools Apa Saja Yang Digunakan?

Dalam membuat website profil ini, memerlukan beberapa tools, yaitu Visual Studio Code (VS Code), Google Chrome, dan Microsoft Edge. VS Code digunakan untuk menulis dan mengedit kode HTML serta CSS. Google Chrome dan Microsoft Edge digunakan untuk mengakses website dan melihat hasil dari kode yang sudah ditulis. Selain itu, kedua browser tersebut juga bisa digunakan untuk memeriksa tampilan website, seperti pengaturan, warna, dan tulisan, agar sesuikan dengan desain yang kita inginkan.

Bagaimana Membuat Struktur Website Menggunakan HTML?

Sebelum membuat website, terlebih dahulu mempelajari dasar-dasar HTML, struktur HTML, serta fungsi-fungsi tag yang digunakan. Setelah memahami dasarnya, materi tersebut mulai diterapkan misalnya dengan membuat halaman profil, hobi, pendidikan, dan kontak dan diatur menggunakan struktur HTML yang rapi dan tersususn, sehingga setiap bagian memiliki arti dan tata letak yang mudah dipahami.

Bagaimana Mengatur Tampilan Website Menggunakan CSS?

Sebelum mulai mengatur tampilan website, terlebih dahulu dipelajari dasar-dasar CSS, mulai dari arti fungsi-fungsi, hingga cara membuat website menggunakan CSS. Setelah mengerti dasarnya, CSS mulai diterapkan ke website yang sudah dibuat sebelumnya. Penerapan awal dilakukan dengan beberapa pengaturan yang sederhana, seperti warna, jenis font, ukuran margin, dan padding. Setelah melihat hasilnya dibrowser, pengaturan dilanjutkan dengan mengatur tampilan dan posisi setiap elemen pada website. Beberapa hal tambahan juga diperbaiki, misalnya tombol dan bayangan di dalam kotak, agar tampilan website terlihat lebih menarik. Proses ini dilakukan secara perlahan, dengan melihat hasilnya dibrowser, kemudian menyesuaikan bagian-bagian yang masih terasa belum sesuai dengan keinginan.

Bagaimana Membuat Navigasi dan Hamburger Menu?

Untuk membuat navigasi diwebsite, digunakan menu hamburger dan ikon-ikon yang dapat menampilkan opsi bagian website saat diklik. Pada tahap ini, masih ada beberapa hal yang belum jelas, khususnya tentang cara membuat navigasi dengan tampilan dan fungsi yang sesuai dengan keinginan. Oleh karena itu, AI digunakan sebagai bantuan untuk mencari contoh code yang bisa dijadikan referensi. Setelah menggunakan kode dari AI, hasilnya mungkin masih belum sesuai dengan keinginan, beberapa bagian mungkin masih diubah dan disesuaikan, baik dalam tampilan maupun fungsi bagian. Pada proses ini, beberapa kesalahan juga muncul karena masih kurang terbiasa menggunakan tag, mengatur posisi elemen, dan CSS. Meskipun ada kendala, setiap bagian yang tidak berjalan baik diperbaiki secara perlahan. Dari proses ini, mulai terlihat bahwa memahami kode tidak hanya cukup dengan menyalinnya, tetapi juga perlu mencoba dan mencari tahu cara kerjanya.

Bagaimana Mengecek Tampilan Website di Mode Mobile?

Setelah website selesai dibuat, tampilan website dicek melalui fitur responsive mode pada Developer Tools yang ada dibrowser. Fitur ini digunakan untuk melihat bagaimana tampilan website ketika dibuka di layar dengan ukuran kecil. Saat memeriksa, beberapa hal harus diperhatikan, misalnya susunan, ukuran, huruf, dan lokasi menu agar tetap terlihat rapi dan nyaman digunakan. Di website profil pribadi ini, tampilan untuk perangkat mobile sudah sesuai dengan cukup baik. Setelah mencoba mengubah ukuran layar, tidak ada masalah pada tata letak yang perlu diperbaiki. Namun, terdapat perbedaan kecil pada warna bayangan kotak di bagian Web Developer. Bagian tersebut kemudian diubah warnanya tanpa mengganggu tata letak elemen yang sudah ada. Setelah diperiksa kembali, tampilan situs web sudah terlihat baik di mode komputer maupun ponsel.

Bagaimana Hasil Akhir Website yang Buat?

Setelah mendalami HTML dan CSS untuk menyusun arsitektur halaman, menata antarmuka visual, serta mengintegrasikan sistem navigasi, profil website pribadi pada akhirnya berhasil diwujudkan sesuai dengan rencana desain yang telah disusun secara detail. Platform digital ini terdiri dari beragam segmen , mencakup profil pribadi , minat , latar belakang pendidikan, serta informasi kontak . Kemampuan navigasi yang tersedia memfasilitasi perpindahan pengguna segmen yang dituju secara lebih efisien dan intuitif. Tampilan situs web selanjutnya divalidasi melalui perangkat PC dan mode seluler guna memastikan integritas visual seluruh komponen di berbagai resolusi layar. Meski website yang dibuat masih terlihat sederhana, proses pembuatannya memberikan pengalaman yang baru dan membantu memperdalam pemahaman tentang cara menggunakan HTML dan CSS dalam merancang sebuah website .

Kesimpulan

Dari proses pembuatan website profil pribadi ini, terlihat bahwa membuat website tidak hanya tentang penulisan kode, tetapi juga memahami fungsi setiap bagian dan mengatur tampilannya agar sesuai dengan desain yang diinginkan. Selama proses pengerjaan, beberapa kesalahan memang terjadi karena masih dalam tahap belajar. Namun, dengan belajar memperbaiki kesalahan sendiri, pemahaman tentang HTML dan CSS semakin meningkat. Pengalaman ini juga membuat saya ingin terus belajar dan meningkatkan kemampuan dalam bidang membuat website.
